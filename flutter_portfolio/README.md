# Himanshu Choudhary — Next.js portfolio

A responsive Next.js recreation of the Flutter portfolio at D:/Projects/Personal/portfolio.

## Run locally

From this project folder:

```powershell
npm install
npm run dev
```

Open http://localhost:3000.

## Production build

```powershell
npm run build
npm start
```

## Update the portfolio

- `app/page.tsx`: introduction, social links, sections, and contact details.
- `app/portfolio-data.json`: all eight projects, skills, and career timeline.
- `app/globals.css`: responsive layout and dark/light theme colors.
- `app/theme-toggle.tsx`: theme switch.
- `app/icons.tsx`: social, technology, and store icons.
- `public/images/`: optimized local WebP images.
- `public/himanshu.pdf`: downloadable CV.

The original Flutter project is unchanged. Project descriptions, download counts, employment dates, and external links are preserved from its source.
